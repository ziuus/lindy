## Contributing

Thanks for contributing to Lindy.

### Before opening a pull request

- Open an issue for bugs, feature requests, or UX changes.
- Keep each pull request focused and easy to review.
- Note any platform assumptions, especially around Linux distributions or dual-boot layouts.

### Local development

```bash
pnpm install
pnpm dev
```

### Validation

- Verify the app still starts locally.
- Check any mount-management changes carefully before requesting review.
- Include screenshots for UI changes when useful.

### Pull request checklist

- Explain what changed and why.
- Link the related issue.
- Avoid unrelated cleanup in the same PR.
